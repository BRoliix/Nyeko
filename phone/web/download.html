Nyeko for iPhoneFrom Safari, no App Store · iOS 16.4 or later

You're on an iPhone in Safari: start at step 2.

Open this page in Safari: other browsers can't add it to the Home Screen.

  1. On the iPhone, open nyeko-phone.pages.dev in Safari.
  2. Tap Share (the square with an arrow), then Add to Home Screen → Add.
  3. Open Nyeko from the Home Screen (not Safari: the Home Screen app keeps its own pairing).
  4. Pair a computer: on it, Nyeko → Phone; scan the code with the Camera app, tap Copy pairing code, then in Nyeko tap Paste pairing code. More computers: Settings › Add a computer.
  5. In Nyeko › Settings: set up Face ID and Turn on alerts.
